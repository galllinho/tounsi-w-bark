## Grammaire (Tunis)

- **Tu = enti, pour un garçon comme pour une fille.** Pas de féminin à la 2ᵉ personne (« enti mchit », « tekhdem ») — *Tunisian Arabic morphology*, Wikipédia ; *Tunisian Arabic*, Wikipédia.
- **Mais les participes et adjectifs s'accordent** : mechi / mechya, jay / jaya, tounsi / tounsiya, kaed / kaeda.
- **Pronoms** : ena (je), enti (tu), houa (il), hiya (elle), ahna (nous), entouma (vous), houma (ils).
- **Possessifs** : -i (esmi), -ek (esmek), -ou (esmou), -ha (esmha), -na, -kom, -hom. Avec un nom en -a, on ajoute -t : khobza → khobzti. Possession avec « mtaa » : el karhba mtaai (ma voiture).
- **Présent** : n- (je), t- (tu), y- (il), t- (elle), n-…ou (nous), t-…ou (vous), y-…ou (ils) : nekhdem, tekhdem, yekhdem, tekhdem, nekhdmou, tekhdmou, yekhdmou.
- **Passé** : -t (je et tu : khdemt), ∅ (il : khdem), -et (elle : khedmet), -na (nous), -tou (vous), -ou (ils).
- **Négation verbe** : ma … ch → ma nhebbech, ma fhemtech, ma fammech (il n'y a pas).
- **Négation phrase nominale et futur** : mouch → mouch ghali, mouch bech nemchi.
- **Être, négatif** : manich (je ne suis pas), mekch (tu n'es pas), mehouch, mehich.
- **Futur** : bech + présent (bech nemchi = je vais aller).
- **En train de** : kaed / kaeda / kaedin + présent (kaedin neklou = on est en train de manger).
- **Questions** : chnoua (quoi), chkoun (qui), win (où), waktech (quand), alech (pourquoi), kifech (comment), kaddech (combien, quantité), bkaddech (combien, prix).
- **Démonstratifs** : hedha (ce, m.), hedhi (cette), hedhoum (ces).
- **Ici** = houni (hna veut dire « nous » dans d'autres parlers : ne pas l'utiliser pour « ici »).
- **Non** = le ; **oui** = ey.
- **Viens** = ija (même forme pour un garçon et une fille).
- **Ya hasra** = nostalgie (« le bon vieux temps ») ; **ya khsara** = « quel dommage ».
- **Prix** : bkaddech (c'est combien ?) ; **quantité** : kaddech (combien ?).
- **S'il te plaît** = brabbi ; **merci** = yaychek / aychek.
- **Nombres** : wahed, zouz (avec un nom : zouz khobzet), thletha, arbaa, khamsa, setta, sabaa, thmenya, tesaa, aachra, hdach, thnach, aachrin, mya, alf. De 3 à 10 le nom est au pluriel (khamsa dinarat), à partir de 11 au singulier (aachrin dinar).

## Points à faire confirmer par un natif

Courants à ma connaissance mais non retrouvés dans une source écrite :

- **bondok** pour les pignons (« tey bel bondok ») ;
- **hassant chaarek** (tu t'es fait couper les cheveux) et la paire **saha / Allah ysalmek** ;
- **waktech nfarhou bik** (c'est quand ton mariage ?) et **rabbi ykammel bel khir** ;
- **nrahnek** (je te parie), **tsob el mtar** (il pleut) ;
- proverbes : **elli fet met**, **kol taakhira fiha khira**, **ya ghrib koun adib**, **ejjar kbal eddar** ;
- **Jedda** ou **Mémé** pour la grand-mère, **tzawej** ou **aaras** pour se marier (selon les familles).
