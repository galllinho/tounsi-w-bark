# Référence de l'algérien (parler d'Alger, l'algérois) pour Tounsi w Bark

Règles et vocabulaire vérifiés contre les sources ci-dessous (recherche du 31 octobre 2026). Tout texte algérien de l'appli (pack « dz ») doit les respecter.
Les sources écrites sur l'algérois *lui-même* sont rares : quand une forme n'a été trouvée que dans une source, ou dans aucune, elle est listée à la fin, dans « Points à faire confirmer par un natif ».

## Écriture latine utilisée dans l'appli (sans chiffres)

| Son | Arabe | Écrit | Exemple |
| --- | --- | --- | --- |
| ع | ع | a / aa (e devant consonne) | aatini (donne-moi), saa (heure) |
| ح | ح | h | hanout, sbah |
| خ | خ | kh | khobz, khouya |
| غ | غ | gh | ghali, ghodwa |
| ق | ق | **q** (à Alger on dit vraiment q, pas k ni g) | qahwa, waqtach |
| ڨ | ڨ | g (mots venus du français ou de la campagne) | gato (gâteau), gasser (bavarder) |
| ش | ش | ch | chwiya, chouf |
| ث | ت | **t** (à Alger, pas de « th ») | tlata (trois) |
| ذ / ظ | د / ض | **d** (à Alger, pas de « dh ») | hada (celui-ci) |
| ج | ج | j | jay, zouj |

- Différence avec le pack tunisien : ق s'écrit **q** (qahwa) et non k ; ث ذ ظ deviennent **t, d, d**.
- Écriture arabe : on écrit comme on prononce à Alger (هادا, هادي, تلاتة, درك), sauf les formules religieuses (الحمد لله, إن شاء الله, بارك الله فيك) qui gardent l'orthographe classique.
- Écriture SMS des jeunes (montrée dans « Lire et écrire », jamais dans le contenu) : 3 = ع, 5 = خ, 7 = ح, 9 = ق, comme en Tunisie.

## Grammaire (Alger)

- **Tu = nta (garçon) / nti (fille).** Contrairement au tunisien de Tunis, le genre compte à la 2ᵉ personne — *Algerian Arabic*, Wikipédia EN ; *Arabe algérien*, Wikipédia FR ; mémoire FAU Erlangen.
  - Présent : tekhdem (tu travailles, garçon) / tekhedmi (fille) ; tekteb / tekketbi.
  - Impératif : khdem / khedmi ; kol / kouli ; rouh / rouhi ; chouf / choufi ; goul / gouli ; aji / aji (viens, même forme).
  - Être : rak (garçon) / raki (fille) : « wach rak? / wach raki? », « kirak / kiraki » (ça va ?).
  - Dans l'appli : `{g:masculin|féminin}` dans le texte (ex. `Wach {g:rak|raki}?` / `واش {g:راك|راكي}؟`).
- **Les participes et adjectifs s'accordent** : rayah / rayha (en train d'aller), jay / jaya (en train de venir), mlih / mliha, dzayri / dzayriya, jdid / jdida, mrid / mrida, aayan / aayana (fatigué).
- **Pronoms** : ana (je), nta / nti (tu), houwa (il), hiya (elle), hna (nous, avec ح), ntouma (vous), houma (ils, elles). Formes appuyées : anaya, ntaya, ntiya.
- **Possessifs** : -i (dari), -ek (darek, même forme garçon/fille), -ou (darou), -ha (darha), -na, -koum, -houm. Avec un nom en -a, on ajoute -t : khobza → khobzti, tomobil → tomobilti.
- **« De, à » = taa / ntaa** : el dar taa khouya (la maison de mon frère), taai, taaek, taaou, taaha, taana, taakoum, taahoum. Jamais « dyal » (marocain) ni « mtaa » (tunisien) dans le pack algérien.
- **Présent** : n- (je), t- (tu, garçon), t-…-i (tu, fille), y- (il), t- (elle), n-…-ou (nous), t-…-ou (vous), y-…-ou (ils) : nekhdem, tekhdem, tekhedmi, yekhdem, tekhdem, nekhedmou, tekhedmou, yekhedmou.
- **Passé** (kteb, écrire) : ktebt (je, tu garçon), ktebti (tu fille), kteb (il), ketbet (elle), ktebna (nous), ktebtou (vous), ketbou (ils). Verbes en -a (kla, manger ; mcha, aller) : klit, kliti, kla, klat, klina, klitou, klaw.
- **En train de / être** : rani, rak / raki, rah, raha, rana, rakoum, rahoum. Rani nekteb = je suis en train d'écrire ; rani labas = je vais bien ; rani hna = je suis là.
- **Futur** (Alger) : **rah + présent** ou **rayah / rayha + présent** : rah nrouh (je vais y aller), rani rayah nakol (je vais manger). « Ghadi » est oranais et marocain : pas dans le pack.
- **Passé continu** : kont + présent (kont nahdar = je parlais).
- **Négation verbe** : ma … ch → ma fhemtch, ma nhebch, makanch (il n'y a pas), ma naarafch (je ne sais pas). Avec « walou » (rien), le -ch tombe : ma qolt walou.
- **Négation nom, adjectif, futur** : machi → machi ghali, machi sahel, machi rah nrouh.
- **Être, négatif** : maniche (je ne suis pas), makch / makich, mahouch, mahich, manach.
- **Il y a** : kayen ; il n'y a pas : makanch.
- **Questions** : wach (quoi / est-ce que), chkoun (qui), win (où), waqtach (quand), kifach (comment), alach (pourquoi), chhal (combien), bechhal (c'est combien, prix), mnin (d'où).
- **Démonstratifs** : hada (ce, m.), hadi (cette), hadou (ces) ; hadak, hadik, hadouk (celui-là…).
- **Ici** = hna (هنا, avec ه) ; **là-bas** = temma. **Nous** = hna (حنا, avec ح) : même son en lettres latines, l'écriture arabe les distingue.
- **Oui** = ih ; **non** = la (lala en insistant).
- **Nombres** : wahed, zouj (deux ; avec un nom : zouj khobzat), tlata, rebaa, khamsa, setta, sebaa, tmanya, tesaa, aachra, hdach, tnach, aachrine, mya, alf. Avec un nom : de 3 à 10 le nom est au pluriel (khamsa dourou), à partir de 11 au singulier (aachrine dinar).

## Lire et écrire (alphabet arabe pour l'algérien)

- Mêmes lettres que pour le tunisien, de droite à gauche, quatre formes selon la place.
- **ڨ** = g (gato, gasser), lettre typique d'Algérie et de Tunisie.
- **ق** se prononce **q** à Alger (qahwa) ; ailleurs en Algérie souvent g.
- **ث ذ ظ** existent dans l'écriture, mais à Alger on les prononce t, d, d : on écrit souvent تلاتة, هادا.
- Écriture SMS : 3 = ع, 5 = خ, 7 = ح, 9 = ق (« saha » = صحة, « 9ahwa » = قهوة).

## Points à faire confirmer par un natif

Courants à ma connaissance mais non retrouvés dans deux sources écrites (ou trouvés dans une seule) :

- **kayen / makanch** (il y a / il n'y a pas), **mazal** (encore, pas encore), **khlas** (c'est fini), **sahit** (bravo, merci), **inchallah**, **mabrouk** ;
- **llah ykhallik** pour « s'il te plaît » (une source donne aafak, une autre yerham babak, une autre men fadlek) ;
- **yaatik essaha** (merci pour le travail, donné seulement comme tunisien par une source) ;
- famille : **khalti** (ma tante maternelle), **ammi** (oncle, et monsieur âgé), **Mima** (grand-mère, mot de famille), **drari** (les enfants), **ya wlidi / ya benti** ;
- **chouf / choufi** (regarde), **rouh / rouhi** (va), **aji** (viens), **kol / kouli** (mange) ;
- **rkhis** (pas cher), **qeddach** (combien, moins fréquent à Alger que chhal), **toul** (tout droit ; une source donne dughri, retenu dans l'appli) ;
- **aam** (année), **chhar** (mois), **simana** (semaine, de l'espagnol, retenu) contre **jemaa** ;
- **tomobil / loto** (voiture), **trig / triq** (route), **bab** (porte), **bit** (chambre), **skhoun / bared** (chaud / froid) ;
- la forme du passé pour « tu » à une fille (**ktebti**, retenue) : un parler d'Alger aurait une forme unique ;
- le futur **rah nrouh** contre **rani rayah nrouh** (les deux sont dans l'appli) ;
- expressions d'humour et d'affection : **ya hasra** (le bon vieux temps), **zaama** (soi-disant), **ya kho** (mon frère, entre amis), **saha ftourek / saha aidek** ;
- karakou (tenue algéroise des mariages), chaâbi, bourek, chorba frik, kalb el louz, zlabia : mots de culture, sans doute justes mais non vérifiés dans une source linguistique.
